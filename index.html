Enterprise Security at Scale

GitHub Advanced Security (GHAS) — CodeQL, secret scanning, push protection, and Copilot Autofix — requires GitHub Enterprise.

  • CodeQL — deepest SAST in the industry
  • Secret scanning with push protection
  • Copilot Autofix — one-click remediation
  • Not available on GitHub Teams
🏢

Entra ID & SSO Integration

GitHub Enterprise supports deep Entra ID (Azure AD) integration for seamless SSO, SCIM provisioning, and team sync.

  • SAML SSO via Entra ID
  • SCIM automated user provisioning
  • Team sync with AD groups
  • GitHub Teams: no SCIM, limited SSO
📋

Governance & Compliance

Enterprise-wide policies, audit logs, and compliance tooling — essential for regulated industries like telecoms.

  • Enterprise-wide policy enforcement

  • IP allow lists & network controls
  • GitHub Teams: limited governance

Full Copilot Integration

Copilot Enterprise, Coding Agent, PR summaries, and custom knowledge bases are exclusive to GitHub Enterprise.

  • Copilot Enterprise tier (full feature set)

  • GitHub Teams: Copilot Business only

Step 2 — Microsoft CAF

Cloud Accelerate Factory (CAF)

The Cloud Accelerate Factory (CAF) is a Microsoft-funded programme delivered by Microsoft CSU engineers at €0 cost to freenet. CAF focuses exclusively on repository migrations — assessing, piloting, and moving freenet's repositories to GitHub Enterprise Cloud in structured waves.

🏭

What CAF covers

Microsoft-Funded · €0 to freenet
  • Delivered by Microsoft CSU engineers — no additional cost
  • Repository inventory, assessment & migration scoping
  • Wave-based repository migration: Assess → Pilot → Scale
  • Source code & history migration to GitHub Enterprise Cloud
  • Post-migration validation & sign-off
⚠️ CAF covers repository migrations only. GitHub Enterprise setup, SSO/SCIM configuration, and developer training are handled separately.
📋

CAF Migration Phases

4-Phase Process
Phase 1

Assessment & Planning

Repository inventory, migration scoping, tooling setup, timeline

Phase 2

Pilot

1–2 repositories migrated and validated — low-risk proof of concept

Phase 3

Scaled Migration

Wave-based rollout of all repositories to GitHub Enterprise Cloud

Phase 4

Validation & Sign-off

Formal sign-off, documentation, and post-migration support
