Promotional entitlement pool expired 1 September 2026

Through August, TK Elevator had a promotional pool of $16,770/month on top of the standard pool of $10,640/month. That is why August billed only $1,915 against $18,745 of gross usage. From September the promotional pool is gone and only the standard pool (551 seats × 1,900 credits = $10,469/month) applies. At August consumption levels, the metered line moves from $1,915 to roughly $8,276/month — a 4.3× increase. This is a change in what is invoiced, not a change in behaviour.

How the break-even is calculated

August Copilot cost  $12,384 ÷ 364 active devs = $34.02 per developer per month
$34.02 ÷ $67.71 per developer-hour = 0.50 hours = 30 minutes / dev / month
As a share of a 160-hour month: 0.31% of engineering capacity

At the forward run-rate of $18,745: $51.50 per dev ÷ $67.71 = 46 minutes / dev / month  (0.48%)

Put differently: if Copilot saves each active developer half an hour a month, the platform is free. Every minute beyond that is net return. Independent field studies place realistic savings in the range of 1 to 3 hours per developer per week, which is 8 to 26 times the break-even threshold.

Assumptions, stated plainly

  • $130,000 fully-loaded annual developer cost. This is GitHub's default modelling figure, not a TK Elevator figure. Substitute the real number and every value scales linearly.
  • 160 productive hours per month, 4.33 weeks per month.
  • 364 active developers, the measured 28-day active count. The 187 idle seats are counted as cost but contribute zero benefit, so the model is conservative.
  • USD throughout. Consumption data is billed in USD; no EUR conversion is applied.
  • Time saved is not measured in this data. It is the one input the customer must supply or accept from benchmark. Everything else on this page is observed.
Next

Three things worth doing

1  Reclaim 187 idle seats

551 seats, 364 active. The 187 seats with no activity in 28 days cost $3,553/month, or $42,636 a year.

Either reassign them to teams on the waiting list or release them at the next true-up. Idle seats also drag down every per-seat metric used to justify the platform internally.

2  Move Phase 1 into Phase 2

315 developers sit in Phase 1 at 112 LoC/day. The 27 in Phase 2 run at 438 LoC/day.

This is an enablement problem, not a licensing one. Agent mode, Copilot CLI and PR review are already available on their seats and barely used — copilot-pr-reviews is 347 AI units out of 1.87 million.

3  Brief finance before the September invoice lands

The metered line moves from $1,915 to roughly $8,276 with no change in developer behaviour, purely because the promotional pool expired. If nobody has flagged this, it will read as a 4× cost overrun. The enterprise budget is $30,000/month with PreventFurtherUsage, so there is no service risk, but there is a credibility risk.

Data gap: pull request telemetry is empty

Every PR metric returns zero — pull requests merged, median time to merge, code-shipped multiplier. Without it there is no cycle-time or throughput story, which is the evidence a CFO will ask for next. Worth confirming whether TK Elevator's repositories sit inside the tke EMU enterprise or whether this is a telemetry gap to raise internally.
