🍪 The basics

It's a shared cookie jar

Every seat you buy adds AI Credits (AIC) to one shared pool for your enterprise. Everyone draws from the same jar. 1 AIC = $0.01 (100 AIC = $1).

1

You get a shared AI Credit pool

Buying seats fills the jar
💰💰💰

How much per seat?

Copilot Business: $19/seat → 1,900 AIC into the pool

Copilot Enterprise: $39/seat → 3,900 AIC into the pool

Example: 1,000 freenet users on Enterprise = 3,900,000 AIC ($39,000) included every month.

2

What consumes credits?

Not all Copilot features eat credits

💸 Draws from the jar

  • Copilot Chat (premium models)
  • Agent mode (in IDE)
  • Copilot Coding Agent (cloud)
  • Copilot Code Review (CCR) — + Actions minutes
  • Copilot CLI
  • Copilot Spaces / Spark
  • Third-party coding agents
  • Agentic Workflows (org-billed)

🆓 Free — never touches the jar

  • Inline code completions (ghost text)
  • Next edit suggestions
  • Unlimited on every paid plan
3

When the jar is empty

Metered billing begins

Once your included credits run out, every additional AIC is billed at the end of the month — only up to the spending budget you set. No budget = no overage allowed.

🚨 Always turn ON "Stop usage when budget exceeded"

Without it, the limit is just a notification — the meter keeps running and you can be billed for unlimited overage.

🛡️ The four guards

Four controls to stay in control

Two guards protect the jar (so one person can't drain it). Two guards protect your wallet (so you can't be billed beyond a cap).

🛡️
GUARD #1 · PROTECTS THE JAR

User-Level Budget (ULB)

For AI Credits → caps TOTAL usage per user (not just overage)

Limits how many AIC one user can consume per month. Set a universal default or override for specific groups. GA since June 1, 2026.

How: Enterprise → Settings → Billing → Budgets → Add user-level budget. For 1,000+ users, use the Budget API.
⭐
GUARD #2 · PROTECTS THE JAR

Individual user overrides

Higher caps for power users

Override the default ULB for specific users (e.g. platform engineers, AI champions) so they get a bigger slice without lifting the cap for everyone.

How: Same Budgets page → "Create budget for specific user" → choose users → set higher amount.
🏦
GUARD #3 · PROTECTS YOUR WALLET

Enterprise spending limit

Caps total additional (overage) spend

The maximum dollar amount your enterprise can be billed beyond included usage. New: you can now also create an enterprise budget that excludes cost-center usage, so specific business units can have their own headroom.

How: Enterprise → Settings → Billing → Budgets → Enterprise-scoped budget. Toggle "Exclude cost-center usage" if needed.
👥
GUARD #4 · PROTECTS YOUR WALLET

Cost-center budget

Caps additional spend per business unit

Group users, repos or orgs into cost centers (e.g. md.de, mobilcom-debitel, Platform Engineering) and cap each one. Enables chargeback, blocks one BU from burning the whole overage. Up to 500 cost centers per enterprise.

How: Billing → Cost centers → Create → assign users/repos/orgs → then Budgets → Create budget scoped to that cost center.

⚠️ What UBB still can't do (today)

• No org-level ringfence of the included pool — heavy users in one org can drain shared credits other orgs were counting on. Workaround: cost-center budgets on the overage side.
• Agentic workflows billed to the org bypass ULBs. Control them via cost-center budgets + the agentic-workflows cost-management tools (gh.io/gh-aw-cost).
• A user / repo / org can be assigned to only ONE cost center at a time. Assigning to a new one auto-removes from the old one.

⚙️ Step-by-step

How to adjust every billing option

Exact paths, what each setting does and the trade-offs — for cost centers, budgets, ULBs, enterprise limits and more.

🏢

Cost center

NEW: 500 max
Enterprise → Settings → Billing & licensing → Cost centers

A cost center is a group of users, repositories or organizations that you want to track and bill together — typically a business unit, brand, product or department. Cost centers are the foundation for chargeback and granular spend control.

enterprise / your-enterprise / settings / billing / cost-centers
  1. Click Cost centers → New cost center
  2. Name it after the business unit (e.g. md.de — Web Platform)
  3. Add resources — pick users, repositories and/or organizations
  4. Save. From now on all UBB usage of those resources is attributed to this cost center
  5. (Optional) Attach a budget — see "Cost-center budget" below
⚠️ A resource can only live in one cost center at a time. Reassigning auto-removes from the previous one. Plan your hierarchy first. The People-page cost-center integration was deprecated in March 2026 — use this page (or the API) only.
✍️

User-Level Budget (ULB)

GA
Enterprise → Settings → Billing & licensing → Budgets

Caps how much one user can consume. For AI Credits, this controls total usage — not just overage — so it directly protects the shared pool. Use a universal default + targeted overrides for power users.

enterprise / your-enterprise / settings / billing / budgets
  1. Click New budget → choose scope User
  2. Select All users for the default, or pick specific users / a group for overrides
  3. Set the budget amount in USD (e.g. $30 / month for standard devs)
  4. Pick the product = GitHub Copilot (or "AI Credits")
  5. Turn ON "Stop usage when budget is exceeded" 🚨
  6. Configure alert thresholds (e.g. 75% & 90% email to admin)
💡 For 100+ users, use the Budget API to roll out the default + per-user overrides programmatically — sync it with AAD group membership.
👥

Cost-center budget

Enterprise → Settings → Billing & licensing → Budgets

Caps total additional (overage) spend for everything assigned to a cost center. The only way to ringfence overage spend per business unit and enable chargeback-style accountability.

budgets / new → Scope: Cost center → pick cost center
  1. Create the cost center first (see above)
  2. Click New budget → scope Cost center → pick it
  3. Set USD cap for additional spend (e.g. $2,000 / month for md.de)
  4. Choose product = Copilot, Actions, Packages, etc. — or "All products"
  5. Turn ON "Stop usage when budget exceeded"
  6. Add notification thresholds and recipients (cost-center owner + finance)
💡 Best practice: combine this with ULBs. Cost-center budget = financial cap. ULB = fair-share inside the cost center.
🏦

Enterprise spending limit (enterprise-scoped budget)

NEW: exclude cost centers
Enterprise → Settings → Billing & licensing → Budgets

The master ceiling on total additional spend for the whole enterprise. Now (preview) supports an option to exclude cost-center usage so you can set a "default-everyone-else" cap and let specific cost centers run with their own budgets.

budgets / new → Scope: Enterprise
  1. Click New budget → scope Enterprise
  2. Set the total USD cap
  3. NEW: Toggle "Exclude cost-center usage" if you want cost centers managed independently
  4. Turn ON "Stop usage when budget exceeded"
  5. Notify enterprise billing managers at 75/90/100%
💡 Ask your GitHub account team to baseline your current AIC consumption before setting this — it's much better than guessing.
🛑

"Stop usage when budget exceeded" toggle

On every budget you create (User, Cost center, Enterprise)

The single most important setting in UBB. OFF = budget is just a notification, charges keep accruing. ON = hard stop, no surprise bills. Always ON unless you have a specific business reason.

🚨 Turn ON for every budget. If a team gets blocked mid-month, you can always raise the budget — that takes seconds. Recovering from a surprise bill takes weeks.
🔔

Budget alerts & email notifications

Configured inside each budget

Trigger emails at custom % thresholds. Always notify both the budget owner (e.g. team lead) and central billing managers, so nobody is surprised when the hard stop kicks in.

  1. Open the budget
  2. Add thresholds (recommended: 50%, 75%, 90%, 100%)
  3. Add recipients — billing managers + cost-center owner
🔌

Bulk management via the Budget & Usage API

GA
REST API · /enterprises/{enterprise}/settings/billing/budgets

Manage the entire lifecycle of budgets via API — create, update, delete, change amount, change alerts. Required for any freenet rollout at scale (hundreds of users / dozens of cost centers).

  1. Generate a PAT or GitHub App with Manage billing permission
  2. POST budgets in bulk from a script driven by AAD group membership
  3. Use the new Usage summary API to pull consumption by org / repo / cost center / SKU for chargeback
  4. Schedule monthly review — adjust ULBs based on actual usage
📘 Docs: Budget API · Usage Summary API
🧐

Copilot Code Review (CCR) runner config

NEW: org-default runner
Organization → Copilot settings → Code review → Runners

Since June 1, 2026, CCR consumes GitHub Actions minutes on top of AI Credits. You can now set a default Actions runner at the organization level instead of per repo. Choose your runner type carefully — large runners burn minutes 10× faster.

  1. Org → Copilot → Code review → Configure runners
  2. Pick a GitHub-hosted standard runner as the org default
  3. Override per repo only when needed (e.g. monorepo needing larger runner)
🤖

Agentic Workflows — bill to org

NEW
Workflow markdown frontmatter + Copilot policy

Agentic workflows can now run with GITHUB_TOKEN instead of a PAT, billing AIC directly to the organization. ULBs do not apply in this mode (no user is attributed), so control these via cost-center budgets + per-workflow caps.

  1. Enable Copilot policy "Allow use of Copilot CLI billed to the organization"
  2. In the workflow frontmatter add permissions: copilot-requests: write
  3. Compile and push the updated lockfile
  4. Add the workflow's org to a dedicated "Automation" cost center with its own budget
  5. Use the agentic-workflows cost-management tools (gh.io/gh-aw-cost) to cap per-run token usage
✅ freenet AG checklist

Six-step rollout for production

UBB setup for freenet AG

  1. Map cost centers to brands / BUsCreate one cost center per legal entity / brand (freenet AG, mobilcom-debitel, md.de, Platform Engineering). Assign all GitHub orgs into them. ≤ 500 supported.
  2. Set a default ULB for "standard developer"~$30 / month covers daily Chat + occasional agent usage. Apply to all users via the API.
  3. Override ULB for power usersIdentify the top ~5% by AIC consumption (Usage metrics API → ai_credits_used) and bump them to ~$80.
  4. Set per-cost-center budgetsEach BU gets its own additional-spend cap. Use the "exclude cost-center usage" enterprise option so BUs are independent.
  5. Set the enterprise master capOne final ceiling for everything else. Ask your GitHub account team to baseline first.
  6. Turn ON "Stop usage" on every budget · review monthlyIf users are blocked → raise budget. If jar lasts the whole month → tighten or expand seats. Use Usage summary API for chargeback reporting.
